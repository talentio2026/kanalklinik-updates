# Kanalklinik Updates

Hier liegen die Installationsdateien und Update-Listen für **Kanalklinik Viewer** und **Kanalklinik Studio** (Windows).

Die installierten Programme fragen beim Start die Liste im Release `aktuell` ab und bieten neue Fassungen zum Installieren an.
Jedes Paket ist mit dem Update-Schlüssel von Kanalklinik unterschrieben; veränderte Pakete werden von den Programmen abgelehnt.

Bitte das Release `aktuell` nicht löschen.
